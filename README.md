# Calculadora IMC

Aplicação desenvolvida em Java utilizando Swing para cálculo do Índice de Massa Corporal (IMC).

## Funcionalidades

- Entrada de peso em kg
- Entrada de altura em cm
- Cálculo do IMC
- Exibição da classificação do IMC

## Tecnologias Utilizadas

- Java
- Swing
